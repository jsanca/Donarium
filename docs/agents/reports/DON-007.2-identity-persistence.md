# DON-007.2 — Identity Persistence

**Status:** COMPLETE
**Owner:** Deep Pro
**Parent:** DON-007 — Initial Owner Setup

## Summary

Implemented the full PostgreSQL persistence layer for the Identity domain:
5 migrations with constraints, 5 pgx repository adapters receiving explicit
DBExecutor, error translation, and 15 integration tests. Migrations run
automatically on startup.

## Physical Schema

| Table | PK | Key constraints | FK |
|---|---|---|---|
| users | id UUID | email UNIQUE | — |
| credentials | id UUID | user_id UNIQUE | users(id) CASCADE |
| organizations | id UUID | slug UNIQUE, slug CHECK | users(id) RESTRICT |
| memberships | (user_id, org_id) | — | users CASCADE, orgs CASCADE |
| platform_grants | (user_id, role) | role CHECK | users CASCADE |

## FK deletion behavior

| Column | ON DELETE | Reason |
|---|---|---|
| credentials.user_id | CASCADE | Removing user removes their credential |
| memberships.user_id | CASCADE | Removing user removes their memberships |
| memberships.organization_id | CASCADE | Removing org removes its memberships |
| platform_grants.user_id | CASCADE | Removing user removes grants |
| organizations.created_by | RESTRICT | Prevent deleting user who owns an org |

## Repository inventory

| Repository | Methods |
|---|---|
| UserRepo | Create, FindByID, FindByEmail, ExistsByEmail |
| CredentialRepo | Create, FindByUserID |
| OrganizationRepo | Create, FindByID, FindBySlug, ExistsAny |
| MembershipRepo | Create, FindByUserAndOrg |
| PlatformGrantRepo | Create, FindByUser |

All receive DBExecutor as explicit parameter. No hidden tx state.

## Error translation

- `23505` with email constraint → `ErrDuplicateEmail`
- `23505` with slug constraint → `ErrDuplicateSlug`
- `pgx.ErrNoRows` → domain-specific Err*NotFound
- Other errors pass through unchanged

## DBExecutor support

Both `*pgxpool.Pool` and `pgx.Tx` implement the anonymous interface:
```go
interface {
    Exec(ctx, sql, args) (pgconn.CommandTag, error)
    Query(ctx, sql, args) (pgx.Rows, error)
    QueryRow(ctx, sql, args) pgx.Row
}
```
The `NewExecutorFromPool` adapter wraps either into `identity.DBExecutor`.

## Tests

15 integration tests (all pass against real PostgreSQL via Docker Compose):
5 user, 2 credential, 5 organization, 2 membership, 1 platform grant.

Each test starts with `cleanAll` — DELETE FROM all tables to avoid cross-test
contamination.
