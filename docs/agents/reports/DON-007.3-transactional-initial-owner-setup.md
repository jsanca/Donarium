**Status:** COMPLETE

## Summary

Implemented the application layer for UC-001: canonical service with full business
workflow, transactional wrapper, Argon2id password hashing, email normalization,
and 9 passing tests covering success, validation errors, and rollback scenarios.

## Architecture

```
CanonicalSetupService (business logic)
  ├── PasswordHasher → Argon2Hasher
  ├── EmailNormalizer → DefaultEmailNormalizer
  ├── PasswordPolicy (from domain)
  └── 5 repository interfaces

TransactionalSetupService (tx boundary)
  ├── CanonicalSetupService
  └── TransactionManager → pgx TransactionManager
```

## Business workflow

```
Validate request fields
→ Verify system not initialized (ExistsAny)
→ Normalize email
→ Validate password policy
→ Verify email uniqueness
→ Hash password (Argon2id)
→ Begin transaction
→ Create User + Credential + Organization + Membership + Platform Grant
→ Commit
```

Any step failure returns domain error. Within transaction: rollback.
