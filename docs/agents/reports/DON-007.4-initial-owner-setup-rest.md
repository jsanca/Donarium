# DON-007.4 — Initial Owner Setup REST API

**Status:** COMPLETE
**Owner:** Deep Pro
**Parent:** DON-007 — Initial Owner Setup

## Summary

Exposed UC-001 through `POST /api/setup` and `GET /api/setup/status` endpoints.
Handlers delegate to SetupPerformer/StatusReader interfaces — zero business logic
in the HTTP layer. Registered via IdentityRuntime (ModuleRuntime contract).

## Endpoints

| Method | Path | Success | Body |
|---|---|---|---|
| POST | /api/setup | 201 Created | `{"userId":"...","organizationId":"..."}` |
| GET | /api/setup/status | 200 OK | `{"initialized":true/false}` |

## Architecture

```
main.go (composition root)
  ├── repos → CanonicalSetupService → TransactionalSetupService
  └── pool → IdentityRuntime(SetupPerformer, StatusReader)
        └── registers: POST /api/setup, GET /api/setup/status

Handler
  ├── SetupPerformer interface → TransactionalSetupService
  └── StatusReader interface → poolStatusReader(pool + OrgRepo)
```
