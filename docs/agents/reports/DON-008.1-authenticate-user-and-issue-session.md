# DON-008.1 — Authenticate User and Issue Session

**Status:** COMPLETE
**Owner:** Deep
**Role:** Implementation Engineer

## Summary

Implemented UC-002 authentication flow: email + password → validation → credential
lookup → Argon2id verification → grants/memberships loading → session token
issuance → authenticated principal response.

Exposed `POST /api/auth/login` with HttpOnly session cookie.

## Architecture

```
POST /api/auth/login
    │
    ▼
LoginHandler (HTTP)
    │
    ▼
AuthenticateUserService (application)
    ├── EmailNormalizer → DefaultEmailNormalizer
    ├── UserRepository → pgx FindByEmail
    ├── CredentialRepository → pgx FindByUserID
    ├── PasswordHasher.Verify → Argon2id constant-time verify
    ├── PlatformGrantRepository → pgx FindByUser
    ├── MembershipRepository → pgx FindByUser (new)
    ├── OrganizationRepository → pgx FindByID
    └── SessionIssuer → HMACSessionIssuer
```

## HTTP Contract

### Request
```
POST /api/auth/login
Content-Type: application/json
{"email": "owner@example.com", "password": "SecurePass1!"}
```

### Response (200)
```json
{
  "principal": {
    "userId": "uuid",
    "displayName": "Maria Owner",
    "email": "owner@example.com",
    "platformRoles": ["super_admin"],
    "organizationContexts": [
      {
        "organizationId": "uuid",
        "organizationName": "Northstar Rentals",
        "organizationSlug": "northstar",
        "role": "owner"
      }
    ],
    "defaultContext": {
      "type": "organization",
      "organizationId": "uuid",
      "role": "owner"
    }
  }
}
```
`Set-Cookie: donarium_session=<signed>; Path=/; HttpOnly; SameSite=Lax`

### Errors (401 — same message for unknown email and wrong password)
```json
{"error": "the email or password is incorrect"}
```

## Session Design

**Format:** `base64url(payload).base64url(hmac-sha256)`
**Payload:** `{"sub":"user-uuid","iat":...,"exp":...}`
**TTL:** 24h default, configurable via `SESSION_TTL`
**Key:** `SESSION_SIGNING_KEY` env var (default: dev key for local/QA)
**Cookie:** HttpOnly, SameSite=Lax, Path=/, Secure=false on HTTP

## Default Context Decision

Per UC-002: user with both `super_admin` and `owner` gets organization context
as default (not platform admin). First organization in memberships list.

## Security Analysis

- Passwords never logged: `slog.Error("login failed", "error", err)` does not include the password
- Password hashes never returned: `AuthenticatedPrincipal` excludes `SessionToken` from JSON via `json:"-"`
- Constant-time comparison: `subtle.ConstantTimeCompare` in Argon2id verify
- Same public message for unknown email and wrong password (UC-002 A2)
- Session token contains only `sub` (user UUID), not permissions or names
- Cookie: HttpOnly (no JS access), SameSite=Lax

## Tradeoffs

- **HMAC vs JWT library**: Chose hand-rolled HMAC to avoid dependency on a JWT
  library. Two lines of crypto + base64. Simple, auditable, no CVEs.
- **Single membership query vs JOIN**: Added `FindByUser` to membership repo with
  separate org lookups. For typical users (1-3 orgs), N+1 is negligible. A joined
  query can be added when performance demands it.
