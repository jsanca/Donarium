# EP-001.01 — Post-login shell, router, and empty-state routing decision

- **Plan:** [EP-001 — First Property Experience](../../plans/DONARIUM-PA-EXP-001-first-property-experience-engineering-plan-proposal.md) (APPROVED r3, 2026-09-02)
- **Assigned Role:** `software-engineer` (v0.2.0)
- **Status:** MATERIALIZED — awaiting Role adoption
- **Depends on:** EP-001.06 (i18n bundles)
- **Blocks:** EP-001.04, EP-001.14
- **Permitted parallelism:** may proceed in parallel with EP-001.02

## Intent and outcome

An authenticated User lands on an authenticated shell. Post-login routing consults `/api/auth/me` and `GET /api/properties` (and, once EP-001.13 lands, pending invitations attributed to the User's email are surfaced only via direct URL entry — not listed here) to decide whether to render Zero Properties, a single Property Home, or the Portfolio. Deep-link entries preserve their return URL through the login cycle.

## Relevant context and requirements

- Only `LoginExperience.tsx` renders today; there is no router. See `client/src/app/App.tsx`.
- `identity/application/authentication/principal_resolver.go` already emits `PlatformRoles`, `OrganizationContexts`, and a deterministic `DefaultContext` on login and on `GET /api/auth/me`.
- Bilingual copy must consume the i18n keys emitted by EP-001.06.
- Design Constitution (`docs/knowledge/design/DonariumDesignConstitution.md`) and the Stitch theme guidance from the plan apply.

## Constraints / established direction

- Client-side routing library chosen and recorded in **ADR-003** (recommendation: React Router).
- No backend changes.
- WCAG AA baseline, visible focus, keyboard navigation, reduced-motion, large touch targets.
- Complies with plan hygiene **H-4** for any client error boundary that surfaces HTTP errors.

## Expected evidence

- ADR-003 authored under `docs/adr/` and linked from the implementation report.
- Manual walk-throughs of Zero Properties → single Property Home → Portfolio branches with the report.
- Deep-link entry demonstrating return-URL preservation across login.
- Report at `docs/engineering/agents/reports/EP-001.01-post-login-shell-and-router.md`.

## Handoff / stop condition

Supplies the routing shell and the authenticated layout. Does not implement property, invitation, or payment behavior; those arrive from EP-001.02, .12, .13, .14. Does not decide product intent; ADR-003 is a technical choice within the assigned Role's authority.
