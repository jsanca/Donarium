## Intent and outcome

A `Property` aggregate exists in the domain with a repository, application service, and HTTP surface. `POST /api/properties` registers a property (identity + classification + address + rental cadence + standard rent). `GET /api/properties` lists properties accessible to the authenticated User per the Property access rule (see plan §Grounding). `GET /api/properties/{id}` returns a Property overview.

## Relevant context and requirements

- No `Property` exists in the codebase; `server/internal/properties/` is an empty placeholder.
- Reuse the existing `TransactionManager` (`identity/pgx/transaction.go`) and `DBExecutor` abstraction.
- Classification enum per plan OP-5: House, Apartment, Condominium, Multi-unit, Commercial, Other. Display name is user-defined and independent.
- Access rule (from plan): a User accesses a Property iff a `PropertyStakeholder` exists tying that User directly OR via a Membership in an Organization stakeholder. `ExternalParty` stakeholders confer no access. The stakeholder relation itself is finalized in EP-001.03; the access seam must be built here to accept stakeholder-based filtering.
- Complies with plan hygiene **H-3** (dedicated `TEST_DATABASE_URL`; explicit failure when unavailable) and **H-4** (JSON error responses for all HTTP outcomes including 405, preserving `Allow`).

## Constraints / established direction

- **No Organization-scope column on `Property`.**
- Additive migration `006_properties.{up,down}.sql` under `server/internal/platform/database/migrations/`.
- All endpoints protected by `RequireAuthentication` (`identity/http/auth_middleware.go`).
- Do not disclose Property existence to unauthorized readers via error shape (final authorization outcome lives in EP-001.07 for the deep-link endpoint).

## Expected evidence

- Integration tests against dedicated `TEST_DATABASE_URL` exercising round-trip, empty list, and unauthenticated access.
- Endpoint tests covering happy paths and error contract.
- Draft SQL for `006_properties` available for EP-001.10 review.
- Report at `docs/engineering/agents/reports/EP-001.02-property-domain-and-endpoints.md`.

## Handoff / stop condition

Property is a first-class entity with the minimum endpoints. Stakeholders, initial tenancy, payment log, and invitations are out of this node.
