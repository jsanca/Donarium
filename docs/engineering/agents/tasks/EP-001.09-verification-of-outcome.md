## Intent and outcome

Independently establish claim → evidence → observation → judgment for the First Property Experience, covering:

- First-access routing decision (Zero Properties / single Property Home / Portfolio).
- Register-property happy path for each of the four relationship options (plan EP-001.03).
- Deep-link authorization for `/properties/:id` (both OP-6 cases).
- Invitation four-outcome authorization on `/api/invitations/{token}/accept`:
  - unauthenticated → **401** and return-URL preservation;
  - not found → **404**;
  - expired → **410 Gone** with the expired outcome envelope (plan A-11);
  - authenticated but wrong recipient → **403**;
  - valid + intended → **201 Created** with the new stakeholder record and `AcceptedAt`/`AcceptedBy` recorded.
- Payment log post-conditions: record appears in list with correct fields; no ledger aggregation.
- Bilingual copy consistency across new UI (ES/EN parity for EP-001 keys).
- A-9 language default behavior in each of {ES locale, EN locale, other locale}.
